# Co-author trailer experiment

Учебный эксперимент с формальным соавторством в GitHub, проведённый 6 октября 2026 года.

## Формат коммита

После описания коммита оставляется пустая строка, затем указывается трейлер:

```text
Co-authored-by: paul01784 <40064575+paul01784@users.noreply.github.com>
```

Используется GitHub noreply-адрес. Эксперимент проверяет распознавание трейлера GitHub и выдачу Pair Extraordinaire после слияния PR. Сам трейлер не подтверждает совместную разработку: в этом упражнении атрибуция формальная.

## Проверка

1. Убедиться, что GitHub распознал оба аккаунта в списке авторов коммита PR.
2. Слить PR, сохранив исходный коммит с трейлером.
3. Проверить страницу достижений профиля; выдача значка подтверждается только его появлением.

[Формат Co-authored-by в документации GitHub](https://docs.github.com/en/pull-requests/how-tos/commit-changes/creating-a-commit-with-multiple-authors).
