# GitHub Achievements Lab

Учебная площадка для работы с ветками, pull requests и достижениями GitHub. Проверено 6 октября 2026 года.

## Достижения, которые можно получить

| Достижение | Основное условие |
| --- | --- |
| Quickdraw | Закрыть issue или pull request в течение 5 минут после открытия. |
| Pull Shark | Иметь как минимум 2 слитых pull request. |
| YOLO | Слить pull request без code review. Дополнительные условия выдачи могут различаться. |
| Pair Extraordinaire | Совместно авторствовать в коммитах слитого pull request. |
| Galaxy Brain | Получить как минимум 2 принятых ответа в GitHub Discussions. |
| Starstruck | Создать репозиторий, получивший как минимум 16 звёзд. |
| Public Sponsor | Поддержать open-source автора через GitHub Sponsors. |

Arctic Code Vault Contributor и Mars 2020 Contributor связаны с историческими событиями; сейчас их получить нельзя. Heart On Your Sleeve и Open Sourcerer были экспериментальными: не следует рассчитывать на их получение.

## Практический порядок

1. Создать отдельную ветку для законченного улучшения.
2. Проверить изменение и открыть pull request.
3. Слить небольшой проверенный pull request в main; для Quickdraw завершить это в течение пяти минут.
4. Проверить появление значка на странице профиля. Выполненное действие ещё не доказывает выдачу достижения.
5. Для Pair Extraordinaire указать реального соавтора через Co-authored-by; для Galaxy Brain отвечать на настоящие вопросы в проектах, где включены Discussions.

Достижения больше не выдаются за активность в официальных Community Discussions GitHub. Это ограничение не распространяется на Discussions других проектов. Приватная активность может зависеть от настроек видимости профиля. Репозиторий содержит только учебные материалы и не использует данные рабочих проектов.
